# 芝士虎整 · 用户词库模板（custom_phrase）
# ---------------------------------------------------------------
# 用法：把本文件复制成  ~/Library/Rime/custom_phrase.txt  即可手工加词；
#       或者直接用 `` ` `` 造一次词，输入法会自动生成 custom_phrase.txt。
#       输入法读的是 custom_phrase.txt，本模板文件不会被读取，
#       这样升级覆盖包时也不会动到你的词库。
# 每行一条：  词<TAB>编码[<TAB>权重]
#   · 分隔符必须是 TAB（制表符），不是空格
#   · 以 # 开头的行是注释
#   · 手工改完在鼠须管里「重新部署」生效；用 `` ` `` 造的词则是立即生效
# 例子（去掉行首的 # 即可使用）：
# 芝士虎整	tiger	99
# 因为	cpa	80
