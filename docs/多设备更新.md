# 增量更新包

客户端更新器已独立为 [viui798/rime-updater](https://github.com/viui798/rime-updater)。
本文只说明本仓库发版时的增量包生成。

## 生成

```bash
python3 tools/make_release_delta.py v0.3.22 v0.3.23 /tmp/cheese-tiger-v0.3.23-update.zip
```

- 只打包运行时资产：`lua/`、`opencc/`、`models/`、`dicts/`、`tiger_dicts/`、`zuci/`
  以及根目录的 `*.yaml` / `*.txt` / `*.json`；
- 不含 `docs/`、`tools/`、`sync/`、`validation/`、`手机精简版/`、万象旧词库、用户数据；
- 删除的文件写进 `update/DELTA.json` 的 `deletions`，由更新器执行；
- 若变更落在 Git LFS 大模型上，`DELTA.json` 标记 `full_required: true`，
  更新器会改用完整包（不会把 400MB 塞进增量包）；
- 同时写出 `<zip>.sha256`，上传时一并带上。

Release 资产命名为 `cheese-tiger-vX.Y.Z-update.zip` 与对应 `.sha256`，更新器按
`-update.zip` 后缀优先选择。

## 上传

```bash
gh release upload vX.Y.Z <update.zip> <update.zip.sha256>
```

## 安装

见 [rime-updater 的 README](https://github.com/viui798/rime-updater#readme)：
自动识别 mac 鼠须管 / 小企鹅 / 元书与 Windows 小狼毫 / 虎韵，校验 SHA256，
跳过用户数据并执行部署。
