# 多设备更新（macOS / Windows）

避免每台设备手动解压、覆盖、重新部署。两个工具都只用 Python 3 标准库，无需安装依赖。

| 工具 | 作用 |
|---|---|
| `tools/make_release_delta.py` | 生成两个 tag 之间的**增量包**（只含运行时文件），随 Release 一起发布 |
| `tools/update_desktop.py` | 在每台机器上**自动识别 Rime 用户目录**，下载（优先增量包）并覆盖、校验、部署 |

## 1. 生成增量包（发版时，只需做一次）

```bash
python3 tools/make_release_delta.py v0.3.22 v0.3.23 /tmp/cheese-tiger-v0.3.23-update.zip
```

- 只打包运行时资产：`lua/`、`opencc/`、`models/`、`dicts/`、`tiger_dicts/`、`zuci/`
  以及根目录的 `*.yaml` / `*.txt` / `*.json`；
- 不含 `docs/`、`tools/`、`sync/`、`validation/`、`手机精简版/`、万象旧词库、用户数据；
- 删除的文件写进 `update/DELTA.json` 的 `deletions`，由更新器执行；
- 若变更落在 Git LFS 大模型上，`DELTA.json` 标记 `full_required: true`，
  更新器会自动改用完整包（不会把 400MB 塞进增量包）；
- 同时写出 `<zip>.sha256`，上传时一并带上。

Release 资产命名固定为 `cheese-tiger-vX.Y.Z-update.zip`（更新器按 `-update.zip` 后缀优先选择）。

## 2. 在设备上更新

```bash
# 看识别到了哪些前端、当前版本、远端最新
python3 tools/update_desktop.py --check

# 只预演，不写盘
python3 tools/update_desktop.py --dry-run

# 正式更新并部署；元书/小企鹅需要时加 --restart
python3 tools/update_desktop.py --yes --deploy --restart
```

常用参数：

| 参数 | 说明 |
|---|---|
| `--source <zip/url>` | 不用 GitHub，直接指定本地包或直链 |
| `--target <目录>` | 手动指定用户目录（可重复），跳过自动识别 |
| `--version vX.Y.Z` | 指定 tag，默认 latest |
| `--deploy` / `--restart` | 执行部署 / 重启前端 |
| `--proxy socks5://127.0.0.1:1080` | 下载走代理 |
| `--cache-dir` / `--no-cache` | 自定义缓存 / 禁用缓存（默认按包 SHA256 复用） |

## 3. 识别的前端

| 平台 | 前端 | 用户目录 |
|---|---|---|
| macOS | 鼠须管 | `~/Library/Rime` |
| macOS | 小企鹅（Fcitx5） | `~/.local/share/fcitx5/rime` |
| macOS | 元书（Cobra） | `~/Library/Application Support/com.ihsiao.inputmethod.Cobra/RimeUserData` |
| Windows | 小狼毫（Weasel） | `%APPDATA%\Rime` |
| Windows | 虎韵及其他 | 扫描 `%APPDATA%` / `%LOCALAPPDATA%` 深度 ≤4，含 `tiger*.schema.yaml` 的目录 |

部署方式：

- 鼠须管：`Squirrel --reload`，找不到时回退 `rime_deployer --build`；
- 小企鹅：`fcitx5-curl /config/addon/rime/deploy`，找不到时按 `--restart` 重启；
- 元书：无命令行部署接口，更新后按 `--restart` 重启，或手动重新部署；
- 小狼毫：`WeaselServer /q` → `WeaselDeployer /deploy` → 重新拉起 `WeaselServer`。

## 4. 不会覆盖你的数据

以下内容始终跳过：

- `*.userdb/`（用户词典与学习记录）、`*.options.yaml`（开关记忆）；
- `user.yaml`、`installation.yaml`、`reverse_freq.txt`、`custom_phrase.txt`；
- `build/`、`sync/`、`lua/kc_count.txt`、`lua/kc_total.txt`、`lua/input_stats_*.lua`；
- 已有的 `*.custom.yaml` 在覆盖前会备份到 `.cheese-tiger-backup/<时间戳>/`。

完整包里的 `models/sentence-fivegram-mobile.bin`（405MB）若目标目录已有同尺寸文件会跳过复制。
成功后写入 `.cheese-tiger-version`，`--check` 的「当前版本」就来自它。

## 5. 私有仓库与认证

仓库是私有的，GitHub API 与资产下载需要 token：

```bash
export GITHUB_TOKEN=$(gh auth token)   # 或 GH_TOKEN
python3 tools/update_desktop.py --check
```

没有 token 时用 `--source` 指向本地已下载的 zip；本地包旁边的 `.sha256` 会自动校验，
没有则提示跳过哈希校验。

## 6. 当前边界

- Windows（小狼毫 / 虎韵）代码路径已实现，但尚未在 Windows 实机跑过，首次使用建议先 `--dry-run`；
- Android（Trime 芝版）与 iOS 尚未接入，仍需手动同步；
- 增量包只解决「文件传输」，方案编译仍由各前端自己的部署流程完成。
