## 7. 升级合并要点

### 7.1 可以直接整包替换

- `lua/tiger_sentence_learning.lua`、`lua/tiger_sentence_correction.lua`（纯新增 / 可选参数，向后兼容）
- `lua/tiger_sentence_cache/fivegram/lexical/ngram.lua`（长期未变）
- `models/`、四个码表 txt、`default-model.json`、`tiger_sentence_ascii.schema.yaml`

### 7.2 必须手工合并

- `lua/tiger_sentence.lua`：以「上游新版为底 + 回填整合」或「整合版为底 + 套用上游 hunk」，两种方向都可；合并后必须复核 §2.2 的 33 处整合仍在。
  - 三方合并基准要用**整合版当初对应的上游基线**，不要用中间的 r2 版本，否则 `learning_stage` 一段会冲突。
- `tiger_sentence.schema.yaml`：只同步上游的默认值/绑定类改动，不要照抄精简版，否则会丢辅助功能。

### 7.3 不要动

`symbols.yaml`（被 tiger / tigress / tiger_sentence 共用）、`rime.lua`（多方案注册表）、`default.custom.yaml`（方案列表）、`tiger_sentence.custom.yaml`（拼音反查补丁）。
旧 `wanxiang_pro` 方案自 v0.3.10 起从方案列表移除，反查统一走五阶模型引擎。

### 7.4 历史踩坑：key_binder 的 Tab 绑定必须与处理器顺序同时改

上游 schema 的 `key_binder` 有 `Tab → Down` / `Shift+Tab → Up`，且整句处理器排在 `key_binder` **之前**。
若只加绑定、不调顺序（`key_binder` 在前），Tab 会被 `key_binder` 消费并替换成 Down，整句处理器收到的是 Down，`state.tab_pending` 永不置位，后果是：

1. Tab 选重学习失效（`learning_stage` 里 `baseline` 走 `submitted_first` 分支）
2. 「Tab 选中后打字母直接确认」失效（`local confirm = state.tab_pending and is_letter`）
3. Tab 选中后的段落续接判断失效（`... or state.tab_pending`）

因为 navigator 仍会用 Down 移动高亮，表面上「Tab 能用」，不易发现。正确的排法是：`recognizer → tiger_kf → tiger_sentence_processor → key_binder → speller`，让 Lua 先处理 Tab，`key_binder` 只在该段无可用菜单时兜底。

## 8. 复现命令

```bash
# 设好路径
SRC=/path/to/芝士虎整
NEW=/path/to/虎整句Rime-20261007-r3-d46fab4-完整包

# 1) 文件层
cd "$NEW" && for f in $(find . -type f | sed 's|^\./||' | sort); do
  if [ ! -e "$SRC/$f" ]; then echo "缺 $f"
  elif cmp -s "$NEW/$f" "$SRC/$f"; then echo "相同 $f"; else echo "不同 $f"; fi
done | sort | uniq -c

# 2) 引擎层差异块
diff -u "$NEW/lua/tiger_sentence.lua" "$SRC/lua/tiger_sentence.lua" | grep -c '^@@'

# 3) 语法与上游测试
luac -p "$SRC/lua/tiger_sentence.lua"

# 4) 方案层组件数
python3 - "$SRC/tiger_sentence.schema.yaml" "$NEW/tiger_sentence.schema.yaml" <<'PY'
import sys,re
def counts(p):
    out={}; top=sec=None
    for line in open(p,encoding='utf-8'):
        s=line.rstrip('\n')
        if re.match(r'^\S',s) and s.endswith(':'): top=s[:-1]; sec=None; continue
        if re.match(r'^  \w',s) and s.endswith(':'): sec=s.strip()[:-1]; out[(top,sec)]=0; continue
        if sec and re.match(r'^    - ',s): out[(top,sec)]=out.get((top,sec),0)+1
    return out
a=counts(sys.argv[1]); b=counts(sys.argv[2])
for k in sorted({k for k in list(a)+list(b) if k[0]=='engine'}):
    print(k[1], a.get(k,0), b.get(k,0))
PY
```
