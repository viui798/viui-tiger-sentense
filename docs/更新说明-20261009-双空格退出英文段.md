## 一、英文段连续两下空格退出

### 使用场景

虎整句的英文段原本需要用 `]` 闭合。手机上输入 `]` 往往要先切到符号页，操作不够方便。

### 现在的行为

在英文段（`[` 之后、`]` 之前）里连续按两下空格：

- 第一次空格仍然写入英文原文，行为与旧版一致。
- 第二次空格不再写入第二个空格，而是等价于按一次 `]`，闭合英文段。
- 闭合后按键回到中文输入。

| 操作 | 结果 |
|---|---|
| `[hello` → 空格 | `[hello ` |
| `[hello ` → 再按空格 | `[hello ]`，英文段闭合 |
| `[hello ` → 输入 `w` → 再按空格 | `[hello w `，不会退出 |
| `[hello ]` → 空格 | 上屏当前候选，仍按闭合后的原规则执行 |
| Tab 选中候选后按空格 | 先完成候选替换并加入空格，行为不变 |

只有输入串末尾已经是空格时，第二次空格才会触发退出。中间输入了字母或其他字符后，再按空格不会误退出。

### 实现

改动位于 `lua/tiger_sentence.lua` 的整句处理器空格分支。英文段内检测到当前输入最后一个字符为空格时：

1. 清除 Tab 待确认和空码状态。
2. 清除提前上屏证据。
3. 向组合串写入 `]`，闭合英文段。
4. 保存临时状态并继续处理后续按键。

该检查位于 Tab 候选替换之后，因此按过 Tab 时仍优先完成候选补全。

### 代价

英文段内无法再用空格键直接输入两个连续空格，因为第二下空格会被解释为闭合英文段。这是本功能的预期取舍，只影响虎整句的英文段；中文编码、普通空格上屏和英文段外的行为不变。
