# 更新说明：虎整句中英混输改进

日期：2026-10-08

本次改动两处，都只影响虎整句（`tiger_sentence`）的中英混输；虎单、虎词与其它功能不受影响。

## 一、英文联想候选显示中文释义

**之前**：英文段未闭合时，词典联想候选的注释固定显示「英文词典」。
**现在**：显示该单词的中文释义；词表里查不到的词仍显示「英文词典」。

| 输入 | 候选与注释 |
|---|---|
| `[hell` | `hello 你好`、`hell 地狱`、`help 帮助` |
| `[open` | `openai 开放人工智能` |

实现要点：

- 新增随包词表 `lua/data/english_chinese.txt`（71,269 条，取自万象 amzxyz/rime_wanxiang），格式为 `单词<TAB>释义`，多条释义用 `；` 连接。
- `lua/tiger_sentence.lua` 新增 `M.inline_english_translation(word)`：**惰性加载**词表（只有用到英文联想时才读），按小写查词，所以 `Hello`、`HELLO` 都能查到。
- 查不到时回退为原来的「英文词典」，行为不变。
- 性能：普通中文输入完全不读这张表。

## 二、英文段内的空格写进原文

**之前**：按 `[` 进入英文后按空格会直接上屏候选，没法输入带空格的英文。
**现在**：空格写进英文原文；只有按 `]` 结束英文段之后，空格才上屏。

| 场景 | 行为 |
|---|---|
| `[hello` 后按空格 | 空格进原文 → `[hello ` |
| `[hello world]` 后按空格 | 上屏（英文段已闭合） |
| `abcd`（纯中文编码）后按空格 | 上屏（行为不变） |

示例：`[hello world]`、`[OpenAI GPT]` 这类带空格的英文都能整段输入。

想跳过某个候选直接上屏时：先按 `]` 收尾再按空格，或直接按 **Enter**。

实现要点：`lua/tiger_sentence.lua` 的 processor 空格分支增加判断——用 `inline_english_open(context)`（有 `[` 但还没出现配对的 `]`）决定是「写进原文」还是「上屏」。

## 三、涉及文件

| 文件 | 改动 |
|---|---|
| `lua/tiger_sentence.lua` | 新增释义查询函数、候选注释改用它、空格分支新增英文段判断 |
| `lua/data/english_chinese.txt` | 新增（71,269 条，约 1.2 MB） |
| `README.md`、`芝士虎整说明.md` | 补充这两项行为的说明 |

## 四、验证情况

- `luac -p` 通过。
- 释义查询：`hello`→你好、`hell`→地狱、`help`→帮助、`world`→世界、`openai`→开放人工智能、未收录词→回退「英文词典」。
- 空格行为（改动前 ✗ / 改动后 ✓）：
  - 英文段未闭合 + 空格 → 进原文，不上屏；
  - 英文段闭合 + 空格 → 上屏；
  - 纯中文编码 + 空格 → 上屏；
  - 完整流程 `[hello world]`：空格进原文 → 继续打 `world` → `]` 闭合 → 空格上屏，内容为 `hello world`。
- 鼠须管部署后运行日志无 ERROR / WARNING。

## 五、升级方式

把这两个文件覆盖到 Rime 用户目录即可：

```
lua/tiger_sentence.lua
lua/data/english_chinese.txt
```

然后重新部署，并完全退出重启前端（Lua 模块按进程缓存，不重启不会重新加载）。
