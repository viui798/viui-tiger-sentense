# 更新说明：虎整句引擎升级到上游 20261009-4eaf42e

日期：2026-10-09

## 一句话

虎整句（`tiger_sentence`）引擎升级到上游 `20261009-4eaf42e`（schema 版本 `1.6.20261009`）：打分规则调整 + 学习记录改为可读的 UTF-8 文本文件；**中英混输、自造词、拼音反查等整合功能全部保留**。

## 一、打分调整

1. **取消单字主码按码长累计的奖励**：`canonical_code_reward` 由 `2.0` 改为 `0.0`。
2. **新增 `whole_single_reward_eligible`**：整个输入一次匹配一个单字时保留 **+5** 奖励，但只有「前 N 高频（N = `high_freq_limit`，默认 1500）且不在白名单」的字才要求用最优码；范围外及白名单单字允许使用码表里已有的非最优码。
3. 新增可调参数 `whole_input_single_character_reward`（限定 0–20），可在 decoder 参数里查看。
4. `supplement.build` 增加 `known` 词集合，用于判断某个文本是否为已知词。

**手感影响**：单字主码不再因为「码更长」而额外加分，部分输入的候选顺序会变化。例如 `ujkf` 由「拾滑、捡」变为「捡、拾滑」。

## 二、学习记录改为文本文件（重要）

| | 之前 | 现在 |
|---|---|---|
| 存储 | LevelDB 目录 `tiger_sentence_learning_<hash>.userdb` | UTF-8 文本 `自学习-tiger_sentence.txt` |
| 模块 | `tiger_sentence_learning.lua` | 新增 `tiger_sentence_learning_text.lua` |
| LevelDB 用途 | 存学习记录 | 仅作跨进程锁（`自学习锁-<name>`） |
| 模式串 | `sentence-v2\|rules=…\|optimal=…\|dup=…` | `整句\|规则版本=…\|最优码限制=…\|单字重码=…` |
| 旧记录 | — | **不迁移**（上游既有规则） |

- 新文件**可读、可编辑**：每行一次人工纠正，列为「操作 / 时间(UTC) / 片段 / 编码 / 前文 / 本次升级 / 模式 / 记录编号 / 撤销目标」。
- 文件上限 16 MiB、最多 10000 条记录。
- 升级后学习记录**从零开始**；旧的 `.userdb` 留着无害（不再被读取），可以自行删除。
- 新存储需要前端提供 `LevelDb` Lua 绑定（用于文件锁）。桌面端都有；**手机前端（元书/同文）需要实测确认**——若缺失，学习会静默失效（只写 `store.error`，不报错）。

## 三、learning.lua 的接口变化

- 新增：`M.plan_levels`、`M.confidence_score`、`M.projected_score`、`M.runtime_index`、`M.refresh_scores`、`M.storage_factory`
- 变化：`M.reinforce_existing(index, raw, before, selected, floor, mode, supplemental)`（多一个可选参数）
- 我们整合所用的接口（`apply_exact_correction_ordering`、`exact_correction_*`、`fusion_*`、`score`、`build`、`diff`、`confirm`、`hash`、`index.partitions/mode/choices`）**全部保留** ✅

## 四、保留的整合功能

中英混输（含英文释义注释与空格行为）、自造词桥接（造词并入组句、Tab 调频与降级、`编码/` 删词）、拼音反查、快符、拆字、emoji、Unicode 提示、简繁四档、计算器、时间日期、输入统计、击键计数、符号菜单与相关快捷键。

合并方式：以新版上游为底回填整合，**三方合并零冲突**；整合的 690 行逐行核对，无缺失、无多余、无合并残留。
