# 上游授权与来源

本文记录芝士虎整与上游虎整句的关系、版本来源，以及公开分发所依据的授权。

## 1. 上游项目

- 仓库：<https://github.com/lvyww/tiger-sentense-rime>
- 许可证：**GPL-3.0**（仓库根目录 `LICENSE`）
- GitHub 上最后一次提交：`9ed168f`（2026-10-10，版本 `1.6.20261010.1`）
- 后续版本作者改为在 QQ 群发布完整包，不再推送到 GitHub

## 2. 本项目与上游的关系

芝士虎整是**个人维护的整合发行版**，不是上游官方仓库：在虎整句引擎与模型的基础上，
加入虎单、虎词、拼音反查与辅助功能。公开发布已获上游作者（QQ 群群主）授权，记录见 §3。

## 3. 授权记录

- 时间：2026-11-04
- 方式：在 QQ 群内获得上游作者授权，维护并公开发布「芝士虎整」整合包（含虎整句引擎与模型）。
- 说明：若权利人认为本仓库内容侵犯其权益，可通过本仓库 Issues 联系我，我会及时删除或调整相关内容。

## 5. 本项目已履行的 GPL 义务

- 仓库与发行包内均保留 `LICENSE`（GPL-3.0）；
- `README.md` 的「授权与第三方组件」列明上游引擎、模型与第三方数据的归属；
- 对上游的所有修改记录在 `CHANGELOG.md` 与 `docs/`；
- 源码公开（模型走 Git LFS，可获取）；
- 发行包继续以 GPL-3.0 分发，未附加额外限制。

## 6. 后续版本的处理规则

1. 从 QQ 群拿到新版后，先确认该版本仍按 GPL-3.0 发布（群内文字或作者确认），再并入公开仓库；
2. 若作者恢复在 GitHub 发版，优先按 `AGENTS.md` §6 的三方合并流程从上游 tag 升级；
3. 每次升级在本文件 §4 追加一行来源记录，保留校验值。
