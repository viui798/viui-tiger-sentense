# 自定义与升级保留指南

本文回答三件事：**改什么 → 文件在哪 → 下次更新方案时怎么搬**。
面向使用者，也面向以后接手维护的人。

相关文档：[`AGENTS.md`](../AGENTS.md)（开发规范）、[`docs/项目日志.md`](项目日志.md)（决策历史）。

---

## 0. 一页总表：哪些文件要保留

`~/Library/Rime` 是鼠须管的用户目录（下称「用户目录」）。发行包只覆盖**方案文件**，不包含用户数据。

| 内容 | 文件 / 路径 | 谁维护 | 升级新包时 |
|---|---|---|---|
| 快符符号表 | `default.custom.yaml` → `patch:` → `kf_symbols` | 本仓库（可自行修改） | **新包会覆盖**：先抄下你的 `kf_symbols` 段，装完后合并回去 |
| 快符特殊键 `;;` `;1` `;2` | `lua/tiger_kf.lua` | 本仓库代码 | 随包更新，普通用户不要改 |
| **自造词** | 用户目录 `custom_phrase.txt` | **你** | **保留**，新包不包含、也不会删它 |
| 自造词模板 | 仓库根 `custom_phrase.example.txt` | 本仓库 | 不用管 |
| **反查调频** | 用户目录 `reverse_freq.txt` | **你** | **保留** |
| 调频开关 | 方案文件 `tiger_sentence.schema.yaml` 的 `tiger_sentence/reverse_frequency` | 本仓库 | 随包更新；想关闭就改新包里的这个键 |
| **虎整句学习** | 用户目录 `自学习-tiger_sentence.txt` | **你** | **保留** |
| 开关记忆 | 用户目录 `tiger.options.yaml` / `tigress.options.yaml` / `tiger_sentence.options.yaml` | **你** | **保留**（删掉 = 恢复默认） |
| 输入统计 | 用户目录 `lua/input_stats_<方案>.lua`（如 `input_stats_tiger.lua`） | **你** | **保留**（删掉 = 清零） |
| 统计名言（可选） | 用户目录 `lua/quote.txt` | **你** | 保留 |
| 鼠须管主题/皮肤 | 用户目录 `squirrel.custom.yaml` | **你** | **保留**（不在发行包里） |
| 方案 / 引擎 / 词库 / 模型 | 新包里的 `*.schema.yaml`、`lua/`、`*.dict.yaml`、`models/`、`symbols.yaml` 等 | 本仓库 | **用新包的覆盖** |

> 一句话：**`custom_phrase.txt`、`reverse_freq.txt`、`自学习-*.txt`、`*.options.yaml`、`input_stats_*.lua`、`squirrel.custom.yaml` 是你的数据，升级时先备份、后放回。**
> `default.custom.yaml` 是方案文件（新包会覆盖），但里面有你改过的 `kf_symbols`，所以要**合并**而不是简单丢弃。

## 1. 改快符

### 1.1 符号表（推荐，只改一个文件）

位置：`default.custom.yaml`，`patch:` 下面：

```yaml
patch:
  schema_list:
    ...
  kf_symbols:
    a: "！"
    b: "_"
    c: "”"
    ...
    z: "“"
```

- 键 = 按 `;` 后跟的字母（只支持 `a`–`z`）
- 值 = 上屏符号；**必须加引号**（符号里含 `:`、`"`、`#`、`[` 时尤其重要）
- 虎单 / 虎词 / 虎整句**三个方案共用这一份**
- 改完保存 → 复制到用户目录 → 重新部署 → 重启前端：

```bash
cp default.custom.yaml ~/Library/Rime/
"/Library/Input Methods/Squirrel.app/Contents/MacOS/rime_deployer" \
  --build ~/Library/Rime "/Library/Input Methods/Squirrel.app/Contents/SharedSupport"
killall Squirrel; open -a "/Library/Input Methods/Squirrel.app"
```

例：想让 `;a` 输出 `；`，就把 `a: "！"` 改成 `a: "；"`。

### 1.2 特殊规则 `;;` / `;1` / `;2`

这三个不是普通字母键，写在 `lua/tiger_kf.lua` 的 `quick_symbol` 里：

| 输入 | 输出 |
|---|---|
| `;;` | `；` |
| `;1` | `：` |
| `;2` | `；` |

普通用户不需要改；要改需要懂 Lua，并在改动后跑一遍 `tools/run_regressions.py`。

### 1.3 单独按 `;` 的两个候选

`;` 的候选 `：` / `；` 定义在 `symbols.yaml` 的 `';'` 行（全角、半角各一处）：

```yaml
';' : [ ：, ； ]
```

- 空格选第一个（`：`），再按 `;` 选第二个（`；`）
- 想调整顺序或增加候选，改这一行即可（同样要重新部署）

### 1.4 改完没生效？

按顺序检查：

1. 文件确实复制到了 `~/Library/Rime/`（不是只改了仓库里的副本）
2. 执行过 `rime_deployer --build`
3. `killall Squirrel` 重启过前端
4. YAML 缩进正确：`kf_symbols` 必须在 `patch:` 下缩进 2 个空格，字母再缩进 2 个空格
5. 值都加了引号

## 2. 自造词

### 2.1 用输入法造词（推荐）

1. 输入 `'` + 编码（例如 `'uawl`），或先打出新词再从〔最近〕候选里选
2. 选中并上屏
3. 词条立即写入 `~/Library/Rime/custom_phrase.txt`，当前会话立即可用

### 2.2 手动加词 / 批量导入

`custom_phrase.txt` 每行一条，**用 TAB 分隔**：

```
词<TAB>编码[<TAB>权重]
```

示例：

```
芝士虎整	tiger	99
因为	cpa	80
```

- `#` 开头是注释行
- 分隔符必须是 TAB（不是空格）
- 手工改完 → 重新部署生效（造词则立即生效）

从模板开始（仓库根目录）：

```bash
cp custom_phrase.example.txt ~/Library/Rime/custom_phrase.txt
```

### 2.3 代码在哪

- `lua/tiger_zaoci.lua`：造词处理器（`'` 前缀、`/` 删词）
- `lua/tiger_sentence.lua` 里的 `zaoci_bridge`：让自造词参与组句与调频（维护者合并上游时必须保留）
- 词条文件：用户目录 `custom_phrase.txt`（**用户数据，不进发行包**）

### 2.4 注意

- 单字自造词会进入白名单，避免被「最优码」规则过滤
- 编码尽量避开常用虎码编码，冲突时按候选顺序选
- 备份/迁移：直接复制 `custom_phrase.txt` 到目标设备的用户目录

## 3. 反查调频

### 3.1 行为

- 只对 **≤8 个字母**的反查生效（长句完全交给五阶模型）
- 同一个拼音下，**主动选过一次非首选词**（翻页/Tab 后空格等），下次它直接排第一
- 选过多个词时按次数降序
- 直接空格选首选**不记录**，避免把「打拼音看虎码」误记成偏好

### 3.2 文件与格式

- 文件：用户目录 `reverse_freq.txt`
- 每行：`全拼<TAB>词<TAB>次数`

```
jiyu	觊觎	1
zhongmu	终幕	2
```

### 3.3 开关 / 清空

- 开关：`tiger_sentence.schema.yaml` 里的 `tiger_sentence/reverse_frequency`（默认 `true`）；改成 `false` 后重新部署
- 清空：删除 `reverse_freq.txt`（或清空内容），重新部署/重启即可恢复模型原始排序
- 迁移：复制该文件到新设备用户目录

### 3.4 代码在哪

- `lua/reverse_freq.lua`：读写与排序
- 三个方案的 processors 里有 `lua_processor@*reverse_freq`
- 文件是**用户数据**，不进发行包

## 4. 虎整句学习

- 文件：用户目录 `自学习-tiger_sentence.txt`（文本日志，**不要手改**）
- 删除该文件 = 清空学习；复制到新设备 = 迁移学习
- 代码：`lua/tiger_sentence_learning.lua`、`lua/tiger_sentence_learning_text.lua`

---

## 5. 开关记忆（`*.options.yaml`）

- `tiger.options.yaml`（虎单）、`tigress.options.yaml`（虎词）、`tiger_sentence.options.yaml`（虎整句）
- 保存你切换过的开关（简繁档位、拆字、Emoji、回删单位、纠错档位等）
- **删掉对应文件 = 恢复默认**；升级时保留 = 开关状态不丢
- 代码：`lua/option_persist.lua`、`tiger_sentence.lua` 的 `M.options`

---

## 6. 输入统计

- 文件：用户目录 `lua/input_stats_<schema_id>.lua`（如 `lua/input_stats_tiger.lua`）
- 可选：用户目录 `lua/quote.txt`（统计消息末尾的名言）
- 删除统计文件 = 清零；升级时保留 = 历史不丢

## 7. 下次更新方案（装新包）的完整步骤

### 7.1 升级前：备份用户数据

```bash
BK=~/Desktop/输入法/芝士虎整/_用户数据备份-$(date +%Y%m%d-%H%M)
mkdir -p "$BK"
cp ~/Library/Rime/custom_phrase.txt "$BK"/ 2>/dev/null
cp ~/Library/Rime/reverse_freq.txt "$BK"/ 2>/dev/null
cp ~/Library/Rime/自学习-tiger_sentence.txt "$BK"/ 2>/dev/null
cp ~/Library/Rime/*.options.yaml "$BK"/ 2>/dev/null
cp ~/Library/Rime/lua/input_stats_*.lua "$BK"/ 2>/dev/null
cp ~/Library/Rime/lua/quote.txt "$BK"/ 2>/dev/null
cp ~/Library/Rime/squirrel.custom.yaml "$BK"/ 2>/dev/null
```

另外：如果你改过 `default.custom.yaml` 的 `kf_symbols`，把这一段复制到备份里（或备份整个文件）：

```bash
cp ~/Library/Rime/default.custom.yaml "$BK"/default.custom.yaml
```

### 7.2 安装新包（覆盖方案文件）

```bash
# 解压新包后，包内顶层目录是 芝士虎整-vX.Y.Z/
ditto "芝士虎整-vX.Y.Z" ~/Library/Rime
```

- 这一步会覆盖：方案 `*.schema.yaml`、`lua/`、`*.dict.yaml`、`models/`、`symbols.yaml`、`default.custom.yaml`
- 不会删你的用户数据（它们不在包里），但 `default.custom.yaml` 会被覆盖

### 7.3 把用户数据放回 / 合并

| 文件 | 放回位置 | 说明 |
|---|---|---|
| `custom_phrase.txt` | `~/Library/Rime/` | 新包不含，通常不用放回；被误删就用备份恢复 |
| `reverse_freq.txt` | `~/Library/Rime/` | 同上 |
| `自学习-tiger_sentence.txt` | `~/Library/Rime/` | 同上 |
| `*.options.yaml` | `~/Library/Rime/` | 同上 |
| `input_stats_*.lua` | `~/Library/Rime/lua/` | 同上 |
| `quote.txt` | `~/Library/Rime/lua/` | 同上 |
| `squirrel.custom.yaml` | `~/Library/Rime/` | 同上（主题/皮肤） |
| **`kf_symbols` 段** | 新包 `default.custom.yaml` 的 `patch:` 下 | **必须合并**：把备份里的 `kf_symbols:` 段粘回新文件，否则你改的快符会丢 |

合并示例（新包 `default.custom.yaml` 里 `patch:` 下加）：

```yaml
patch:
  schema_list: ...
  kf_symbols:
    a: "！"      # ← 换成你自己改过的值
    ...
```

> 不要直接用备份的整个 `default.custom.yaml` 覆盖新包的，否则会丢掉新包对方案列表/热键的更新。只合并 `kf_symbols` 段。

### 7.4 重新部署 + 重启 + 验收

```bash
"/Library/Input Methods/Squirrel.app/Contents/MacOS/rime_deployer" \
  --build ~/Library/Rime "/Library/Input Methods/Squirrel.app/Contents/SharedSupport"
killall Squirrel; open -a "/Library/Input Methods/Squirrel.app"
```

验收清单：

- [ ] `;a` → `！`；`;` 出两个候选；`;;` → `；`
- [ ] 自造词：输入你自造词的编码能查到
- [ ] 反查：`` `nihao `` 出候选；调频词仍置顶
- [ ] 学习：`自学习-tiger_sentence.txt` 文件还在，大小没归零
- [ ] 开关状态：简繁/拆字/回删等和升级前一致

### 7.5 手机端

手机（元书/同文）的 Rime 用户目录同样保留这些用户数据文件；换包时按 7.1 备份、7.3 放回。

## 8. 维护者：把本仓库升级到新的上游虎整句包

上游包（如 `虎整句Rime-1.6.20261030.1`）与本仓库的差异集中在下面这些文件。**升级前先把它们提取/保留，升级时按右列放回**：

| 文件 | 本仓库位置 | 新上游包里的位置 | 处理方式 |
|---|---|---|---|
| 整合版虎整句方案 | `tiger_sentence.schema.yaml` | 同名（4.7KB 精简版） | **绝不整文件覆盖**，按块合并（先保留本仓库版本） |
| 引擎（含本地集成） | `lua/tiger_sentence.lua` | `lua/tiger_sentence.lua` | 用三方合并；保留 zaoci 桥接、用户词排序、✨ 注释、全局表 |
| 全局配置 | `default.custom.yaml` | 上游无 | 保留本地；`kf_symbols`、`schema_list`、热键、`save_options`、ascii 设置都在这里 |
| 标点表 | `symbols.yaml` | 上游无（或精简版） | 保留本地 40KB 万象表（含 `;` 两候选） |
| 模块注册 | `rime.lua` | 上游精简版 | 保留本地注册（zaoci、shift_upper、kf、mixed、pinyin、reverse_freq、option_persist…） |
| 本地 Lua 模块 | `lua/` 下的 `tiger_zaoci.lua`、`shift_upper.lua`、`tiger_symbol_select.lua`、`tiger_kf.lua`、`tiger_mixed.lua`、`tiger_sentence_pinyin*.lua`、`reverse_freq.lua`、`option_persist.lua`、`input_statistics.lua`、`key_counter.lua`、`set_schema.lua`、`yin_pick.lua` 等 | 上游无 | 原样保留在 `lua/`，不要被上游同名文件覆盖 |
| 上游新增文件 | — | `lua/*.lua`、`docs/*`、`tiger_sentence.*.txt`、`pinyin.codes.*` | 按上游路径放进本仓库对应位置 |
| 词库/模型 | `dicts/`、`models/`、`pinyin.qp.codes.txt` 等 | 同名 | 用上游新版覆盖；模型保持 LFS |

合并后的固定动作：

1. **覆盖审计**：上游 schema 的 switches / processors / segmentors / translators / filters / key_binder / `M.*` 导出逐项确认存在（见 `AGENTS.md` §6）
2. 跑 `tools/test_rime_contract.lua` 与 `tools/run_regressions.py`
3. 更新 `CHANGELOG.md`、`docs/项目日志.md`、`RELEASE.json`
4. 打包、部署、发 Release
