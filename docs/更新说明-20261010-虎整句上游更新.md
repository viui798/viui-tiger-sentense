# 更新说明：虎整句上游更新（v0.2.8 / 1.6.20261010.1）

日期：2026-10-10

## 更新方式

以当前芝士虎整整合版为底，使用旧上游 `4eaf42e` 和新上游 `9ed168f` 做三方合并。只更新虎整句核心 Lua 和方案中的上游字段，不覆盖共享配置。

## 核心变化

- `lua/tiger_sentence.lua`：加入自动选重最低码数、正码片段跨前缀学习、Direct/组句来源排序和旧学习模式过滤。
- `lua/tiger_sentence_learning.lua`：加入 `selection_events`，忽略 `fusion-v1|` 与 `exact-correction-v1|` 旧记录。
- `lua/tiger_sentence_learning_text.lua`：解析旧记录时按新模式过滤，原始文本行保留。
- `tiger_sentence.schema.yaml`：版本更新为 `1.6.20261010.1`，增加 `auto_select_min_code_length: 3`，提前上屏首次默认改为开启。

## 保留的辅助功能

以下文件和配置没有被新包覆盖：

- `rime.lua`
- `default.custom.yaml`
- `symbols.yaml`
- `tiger_sentence.custom.yaml`
- 拼音反查、造词、快符、简繁、拆字、Emoji、Unicode、计算器、时间日期、输入统计和击键计数相关模块

方案中的 processors、segmentors、translators、filters、dependencies、recognizer 模式和快捷键均保持原整合结构。中英混输的 `[` / `]`、英文中文释义、英文段 Tab 续接和双空格退出也保留在核心 Lua 中。

- 源码 A/B 对照：关闭五阶模型和开启五阶模型各生成 15,128 条快照，当前整合版与新包结果完全一致。

## 升级方式

推荐直接下载 Release 中的 `cheese-tiger-v0.2.8.zip`，解压后将内容复制到 Rime 用户目录，执行“重新部署”并完全退出重启前端。

从旧版手工升级时，至少更新：

```text
lua/tiger_sentence.lua
lua/tiger_sentence_learning.lua
lua/tiger_sentence_learning_text.lua
tiger_sentence.schema.yaml
```

`rime.lua`、`default.custom.yaml`、`symbols.yaml`、`tiger_sentence.custom.yaml` 和所有辅助模块保持原有配置；用户学习文件、选项和自造词不需要删除。
