# 芝士虎整更新说明

本次更新主要改进虎整句的中英混输和输入统计。

## 虎整句中英混输

- 在中文整句中用 `[` 开始英文片段，用 `]` 结束；英文按原样保留，可继续输入后续中文。
- 英文片段未结束时，输入两个及以上字母即可显示英文词典联想。
- 开启提前上屏时，按 `]` 会确认并上屏当前混输候选，候选包含英文原文；随后输入中文可继续使用中文自动上屏。
- 修复中文前缀已经自动上屏后，继续输入中英混合内容时候选消失的问题。
- 在进入英文和返回中文的切换提示中分别显示 `[西文]`、`[中文]`。

## 输入统计

- 重整日、周、月、年统计报告，提供短报告和详细报告，展示速度、准确性、词长与码长分布等信息。
- 增加累计输入字数对应的 20 级称号和境界进度，并提供 `/scj` 或 `//6` 查看生涯段位。
- 统计报告统一显示前端英文代号，并在前端提供版本信息时一并显示；补充 Android 前端识别。
- 调整报告排版、进度条样式和名言折行显示。

## 使用提示

- 中英混输仅适用于虎整句方案。
- 自动提交英文片段需要开启虎整句的“提前上屏”选项；关闭时可按空格或其他候选键手动上屏。
- 输入统计命令与报告格式以当前方案配置为准。
