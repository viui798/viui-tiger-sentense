# 手机精简版（Android / 元书 / 同文）

## 解决什么问题

Android 前端部署时如果弹出：

```
E/mapped_file.cc:112 attempt to open non-existent file '…/build/wanxiang_pro.prism.bin'.
E/prism.cc:83 error opening prism file '…/build/wanxiang_pro.prism.bin'.
E/dictionary.cc:267 Error loading prism for dictionary 'wanxiang_pro'.
```

说明部署没能编译出 `wanxiang_pro` 的拼写索引（prism）。

**先确认不是另一种问题**：如果报错路径里**用户目录出现了两次**（形如
`/sdcard/android/rime//sdcard/android/rime/lua/data/charset.reverse.bin`），
那是路径拼接问题，与本目录无关——由 `lua/wanxiang/charset_filter.lua` 的相对路径修复解决（v0.2.2）。

## 为什么原版在手机上会失败

`wanxiang_pro.dict.yaml` 会 import 这些词库（源文件合计约 96MB、约 155 万条）：

| 文件 | 体积 | 条目 |
|---|---|---|
| `dicts/jichu.pro` | 58 MB | 1,474,339 |
| `dicts/shici.pro` | 21 MB | — |
| `dicts/lianxiang.pro` | 13 MB | — |
| `dicts/diming.pro` | 3.1 MB | — |
| `dicts/zi.pro` | 748 KB | 51,040 |
| `zuci/moegirl`、`zuci/ext`、`duoyin.pro`、`cuoyin.pro` | ~2.1 MB | — |

编译产物在桌面端是 **table 96MB + prism 30.6MB**。手机内存/时间不够时，建表或建 prism
会中途失败，`build/wanxiang_pro.prism.bin` 就没生成。

## 用法

1. 把本目录的 `wanxiang_pro.dict.yaml` 覆盖到手机 Rime 用户目录**根**，例如
   `/sdcard/android/rime/wanxiang_pro.dict.yaml`
2. 把本目录的 `dicts/zi.common.dict.yaml` 放进用户目录的 `dicts/`，例如
   `/sdcard/android/rime/dicts/zi.common.dict.yaml`
3. 重新部署，耐心等待
4. 检查 `build/`：应出现 `wanxiang_pro.table.bin` 与 `wanxiang_pro.prism.bin`，体积见下表

> 如果之前部署失败过，建议先删掉 `build/wanxiang_pro*.prism.bin` 再部署——实测 librime
> 只在 prism **缺失**时才重建它，残留的旧 prism 不会因为词库变化而自动更新。

## 实测效果（macOS + librime 1.16 实测）

| 词库方案 | 条目数 | table.bin | prism.bin |
|---|---|---|---|
| 原版（全部词库） | ~1,555,000 | 96 MB | 30.6 MB |
| **本手机版**（zi.common + duoyin + cuoyin） | ~10,500 | **380 KB** | **4.7 MB** |
| 只留 cuoyin（完全不要反查时的极限） | 148 | 18 KB | 266 KB |

另外四个变体 prism（`_qp` / `_zrm` / `_mspy` / `_sogou`）桌面端各约 2.6MB，手机版会同步变小。

## 保留 / 失去

**保留**

- 常用字拼音反查：`'ni` → 你（覆盖权重最高的 4,704 个汉字）
- 多音词组（`duoyin.pro`，5,390 条）
- 错音错字兼容（`cuoyin.pro`，148 条）

**失去**

- 生僻字反查（不在 5,000 条常用字内）
- 词组联想反查（`'nihao` → 你好 这类来自 `jichu` 大词库）

## 桌面端不受影响

本目录是仓库里的附加文件。Rime 只读用户目录根下的 `*.schema.yaml` / `*.dict.yaml` /
`*.custom.yaml`，**不会读取子目录**，所以桌面端继续用根目录的原版
`wanxiang_pro.dict.yaml`，行为完全不变。

## 如果连反查也不要（最省资源）

1. `tiger.schema.yaml`、`tigress.schema.yaml`、`tiger_sentence.schema.yaml` 的
   `dependencies` 去掉 `wanxiang_pro_qp`、`wanxiang_pro_zrm`、`wanxiang_pro_mspy`、`wanxiang_pro_sogou`
2. 把 `tiger.custom.yaml`、`tigress.custom.yaml`、`tiger_sentence.custom.yaml` 改名停用
   （反查的 `dictionary: wanxiang_pro` 都写在这三个补丁里）
3. `default.custom.yaml` 的 `schema_list` 去掉 `wanxiang_pro`

这样完全不会编译这张词库，部署最快，也不会再报 prism 相关的错。

## 生成方式

`dicts/zi.common.dict.yaml` 由 `dicts/zi.pro.dict.yaml` 取**权重最高的 5,000 条**生成
（该文件本身按 `sort: by_weight` 排序），字段格式原样保留，只改了 `name` / `version`。
要调整规模，改条数重新生成即可。
