# 芝士虎整

芝士虎整是一套面向 Rime 的虎码方案整合包。它把虎单、虎词、虎整句和万象拼音反查放在同一套配置中，并保留造词、简繁四档、拼音与拆字注释、Emoji、Unicode 提示、计算器、时间日期、输入统计等辅助功能（中英混输已于 v0.2.8.2 移除）。

当前虎整句引擎为上游 `虎整句Rime-1.6.20261010.1`（源码提交 `9ed168f`），方案版本 `1.6.20261010.2`，语言模型仍为 D89-r3 五阶模型。发布包见 GitHub Releases，仓库地址为 <https://github.com/viui798/viui-tiger-sentense>。

## 方案一览

| 方案 ID | 显示名 | 用途 |
|---|---|---|
| `tiger` | 虎单 | 单字优先，适合逐字输入和精确选字 |
| `tigress` | 虎词 | 词组优先，适合常用词组输入 |
| `tiger_sentence` | 虎整句 | 连续输入，由五阶语言模型组句；主要辅助功能集中在这里 |
| `wanxiang_pro` | 万象拼音 | 虎单/虎词的拼音反查词典（虎整句的反查自 v0.4.0 起走五阶模型引擎） |

`default.custom.yaml` 默认把上述四个方案加入方案列表。虎单、虎词、虎整句共用虎码编码、自造词、拼音反查、简繁转换和大部分辅助工具。`tiger_sentence_ascii` 是虎整句包内的内部 ASCII 配置，供 `lua_processor@tiger_sentence_ascii`（上游同款）在 buffered 状态下切换西文时使用，不应加入方案列表。

## 主要能力

- **三种虎码输入方式**：单字、词组、连续整句可以按场景切换。
- **（v0.2.8.2）中英混输已移除**：`[` 与 `]` 直接上屏半角方括号，不再有英文段、词典联想与四候选菜单。
- **自造词**：用单引号进入造词模式，写入用户目录的 `custom_phrase.txt`，并在当前会话立即生效。
- **拼音反查（v0.3.3 分页索引）**：虎整句里的反查候选由五阶模型组句，支持小鹤双拼、全拼、自然码、微软双拼和搜狗双拼，运行时切换，无需重新部署；反引号前缀触发，全拼打法支持简拼（`jsj` → 计算机）。
- **简繁四档**：简体、通繁、港繁、臺繁，词表和地区词组经过 OpenCC 官方表合并与验证。
- **整句学习**：Tab 选中候选后可以学习；正码片段可跨前缀复用，学习记录为 UTF-8 文本文件，便于查看、备份和迁移。
- **字集切换**（虎整句）：常用字集 / 全字集，默认常用，`Ctrl+J` 或方案菜单切换并长期保存；清单见 `tiger_sentence.common_characters.txt`（空清单 = 空字集）。
- **三档回删**（虎整句）：回删编码 / 回删整字（默认）/ 先编码后整字，`Backspace` 按选中的单位删除，跨会话保存。
- **辅助工具**：快符、拆字、拼音、Emoji、Unicode 字符集与编码、数字大写、计算器、符号菜单、日期时间和输入统计。
- **Shift 大写直出**：中文态且没有编码时，按 Shift 再打字母会直接上屏大写字母（不进入虎码编码、不出中文候选）；手机前端发 `Shift+a`、大写 `A` 或只发一次 `Shift_L` 都能生效。
- **虎单/虎词 `;` / `'` 顶字**：候选不足时这两个选重键改为顶字并输出标点（`rjk;` → `符；`）；候选够数时仍是正常次选/三选。
- **手机精简词库**：仓库提供 Android、元书、同文等前端使用的精简版万象词库，不进入桌面发行包。

## 安装

### 前置条件

1. 安装支持 `librime-lua` 的 Rime 前端，例如 macOS 鼠须管、Windows 小狼毫、Linux Fcitx5、Android 元书或同文。
2. 确认前端使用正常版本的 Rime 用户目录。
3. 虎整句需要随包语言模型。直接使用 Release 压缩包时，模型已经包含在包内。
4. 如果从 Git 仓库安装，仓库中的大模型使用 Git LFS。克隆后模型必须是实际二进制文件，不能只是 LFS 指针；必要时运行 `git lfs pull`，或者改用 Release 压缩包。

### 安装步骤

1. 找到当前前端的 **Rime 用户目录**。常见位置：
   - macOS 鼠须管：`~/Library/Rime`
   - Windows 小狼毫：`%APPDATA%\Rime`
   - Android 元书/同文：通常由前端设置页显示，例如 `/sdcard/android/rime`
2. 备份用户目录中的个人配置和用户数据。至少包括：
   - `default.custom.yaml`
   - `*.custom.yaml`
   - `custom_phrase.txt`
   - `tiger_sentence.options.yaml`
   - `自学习-tiger_sentence.txt`
   - `自学习锁-*.userdb`
   - `lua/input_stats_*.lua`
   - `lua/kc_*.txt`
3. 将发行包中的运行时文件复制到用户目录，保留原有目录层级：
   - 根目录方案与词表：`*.schema.yaml`、`*.dict.yaml`、`*.custom.yaml`、`rime.lua`
   - `lua/`：全部 Lua 模块和 `lua/data/`
   - `models/`：虎整句五阶模型和词先验
   - `dicts/`、`tiger_dicts/`、`zuci/`：虎码、万象和辅助词表
   - `opencc/`、`symbols.yaml`、`kf.dict.yaml` 等运行依赖
4. 如果用户目录中已有自己的 `default.custom.yaml`，不要盲目覆盖。应当合并方案列表和快捷键配置，或者先备份再替换。
5. 在 Rime 前端执行“重新部署”。
6. 从方案菜单中选择虎单、虎词、虎整句或万象拼音。

发行包已经排除 `tools/`、`validation/`、`手机精简版/` 和上游身份资料，这些目录只用于开发、验证或手机附加安装。不要把发行包当成源码仓库的完整副本。

### 部署后的快速检查

- 方案菜单中能看到四个方案。
- 输入 `` `nihao `` 能出现拼音反查候选。
- 输入 `'` 加虎码能进入造词模式。
- 虎整句输入 `ujkf` 等编码能看到整句候选；`[` 与 `]` 直接上屏半角方括号。
- `models/sentence-fivegram-mobile.bin` 存在且不是 LFS 指针文件。
- 日志中没有 `lua`、`model`、`prism` 或 `dictionary` 加载错误。

## 日常输入

| 操作 | 虎单 / 虎词 | 虎整句 |
|---|---|---|
| 上屏首选 | `Space` | `Space`，英文段未闭合时例外 |
| 选候选 | 数字、分号、反引号等 | 数字、分号、反引号等 |
| 清空 | `Esc` | `Esc` |
| 上屏原始编码 | `Return` | `Return` |
| 候选移动 | 按各方案绑定 | `Tab` / `Shift+Tab` |
| 翻页 | `-` / `=` | `-` / `=` |
| 切换方案 | `Ctrl` 加反引号 | `Ctrl` 加反引号；小狼毫配置另有 `Ctrl+F8` |
| 切换中文/英文模式 | `Shift` 左右键按配置提交当前编码并切换 | 同左 |

## 虎整句

虎整句由五阶语言模型负责连续输入和候选排序。它加载以下模型：

| 文件 | 作用 |
|---|---|
| `models/sentence-fivegram-mobile.bin` | 五阶语言模型，约 387 MiB |
| `models/tiger_sentence.lexical.bin` | 紧凑词先验，约 148 KiB |

方案默认值写在 `tiger_sentence.schema.yaml`，用户改动保存在用户目录的 `tiger_sentence.options.yaml`。

### 主要选项

| 选项 | 状态 | 说明 |
|---|---|---|
| `tiger_sentence_early_commit` | 提前上屏关 / 开 | 是否允许自动提前上屏 |
| `tiger_sentence/auto_select_min_code_length` | 0～128，默认 3 | 分段非首选单字参与隐式选重的最低码数；0 表示禁用 |
| `tiger_sentence_early_commit_to_preedit` | 提前上屏至应用 / 编码 | 提前上屏时写入应用还是写入编码区 |
| 按键纠错 | 关 / 弱 / 中 / 强 | 错键惩罚分别为关闭、8、6、4；纠错候选的注释默认显示 ✨ |
| `tiger_sentence/correction_mark` | 任意字符串，默认 `✨` | 纠错候选的注释符号，改后需重新部署或重启前端 |
| 简繁 | 简体 / 通繁 / 港繁 / 臺繁 | 四档单选 |
| 字集（虎整句） | 常用字集 / 全字集 | `Ctrl+J`；清单见 `tiger_sentence.common_characters.txt` |
| 回删单位（虎整句） | 回删编码 / 回删整字 / 先编码后整字 | 默认整字；保存到 `tiger_sentence.options.yaml` |
| `pinyin` | 拼音注释关 / 开 | `Ctrl+P` |
| `chaifen` | 拆字注释关 / 开 | `Ctrl+Shift+J` |
| `emoji_cn` | Emoji 关 / 开 | `Ctrl+I` |
| `charset_comment_filter` | Unicode 字符集提示 | `Ctrl+U` |
| `udpf_switch` | Unicode 编码显示 | `Ctrl+Y` |
| `yin` | 拼音反查关 / 开 | `Ctrl+Q` |

上表的辅助开关（含简繁四档和拼音反查打法）从 v0.3.2 起会保存到
`tiger_sentence.options.yaml`，重启输入法、重新部署或切换应用后仍然生效；
`ascii_punct`、`full_shape`、`ascii_mode` 仍按 Rime 惯例每个输入会话复位。

默认设置：

- 提前上屏关闭。
- 单字重码组句开启。
- 按键纠错关闭。
- 高频字最优码限制为前 1500 字。
- 内存配置为 `compact`，以降低移动端和低内存环境占用。

### 中英混输（已移除）

中英混输已于 v0.2.8.2 整体移除：recognizer 不再注册 `inline_english` 模式，`[` 与 `]` 直接上屏半角方括号，不再有英文段、词典联想、中文释义与四候选菜单。

- `Shift` 切换中英文模式的行为不变（Caps、Shift 规则见 `ascii_composer` 配置）。
- 若需按 `[` 直接输出中文括号，可将 `tiger_sentence.schema.yaml` 中 `punctuator/half_shape` 的 `'[': '['` 改为 `'[': '【'` 后重新部署。
- 移除原因：混输英文段在部分前端（Trime、小狼毫）触发解码与常驻内存问题，导致后续正常输入持续卡顿。历史细节见 `CHANGELOG.md` 与 `docs/更新说明-20261011-统计与滤镜性能修复.md`。
- 历史功能文档（混输 Tab、双空格退出等）见 `docs/` 目录，仅作历史记录。

## 自造词

三个虎码方案都支持造词。造词数据保存在 Rime 用户目录的 `custom_phrase.txt`，不会随发行包分发。

### 造词方式

1. 输入单引号 `'` 加虎码编码，例如 `'uawl`，从候选中选词并上屏。
2. 先正常输入并上屏一个词，再输入单引号和目标编码，从标记为 `〔最近〕` 的候选中选择该词。
3. 造词成功后，词条写入 `custom_phrase.txt`，当前会话立即可以按编码查到，不需要重新部署。
4. 在虎整句中，自造词也会进入组句候选和 Tab 学习路径。

### 删除自造词

输入该词编码并加 `/`，例如 `aaaa/`，选择带 `〔删词〕` 标记的候选。只有该编码下存在自造词时，`/` 才作为删词入口。删除会写回文件，并刷新当前会话的内存词库。

### 文件格式

`custom_phrase.txt` 使用 UTF-8 文本，每行格式为：

```text
词<TAB>编码[<TAB>权重]
```

字段之间必须使用 Tab。以 `#` 开头的行为注释。包内 `custom_phrase.example.txt` 只是示例，不会自动加载。手动编辑后需要重新部署。

如果已有词在其他设备不可用，先检查该设备的用户目录是否存在 `custom_phrase.txt`，再检查词条编码和文件可写性。跨设备使用时，把该文件同步或复制到各设备的 Rime 用户目录。

## 拼音反查

在虎码方案中输入反引号加拼音，例如 `` `nihao ``。默认使用小鹤双拼。输入以下命令可以切换反查打法，切换立即生效：

| 命令 | 打法 | 示例 |
|---|---|---|
| `/flypy` | 小鹤双拼 | `` `nihc `` → 你好 |
| `/pinyin` | 全拼 | `` `nihao `` → 你好 |
| `/zrm` | 自然码 | `` `nihk `` → 你好 |
| `/mspy` | 微软双拼 | `` `m;tm `` → 明天 |
| `/sogou` | 搜狗双拼 | `` `m;tm `` → 明天 |

`Ctrl+Q` 可以开关反查。一次只有一种打法生效。v0.3.3 起反查使用**反引号前缀**；单引号改为造词；「拼音+反引号」的后缀式反查暂时移除。

**虎整句里的反查引擎（v0.3.3）**：候选由五阶语言模型组句，长句（整句拼音）可以直接一句话排出；
候选注释仍显示〔拆分·虎码〕，打拼音查虎码的用法不变。要点：

- **全拼简拼**：全拼打法下输入首字母串，如 `` `jsj `` → 计算机、`` `nh `` → 你好（词首字母匹配）。
  字级首字母串（如 `` `js ``）不组句，与旧行为一致；**双拼打法下简拼不可用**（双拼码位会吃掉首字母）。
- **音节级标记（v0.3.4）**：反查时可在每个音节前加 `` ` ``，例如 `` `cai`xu`kun ``；
  短输入会列出多条单字组句候选（蔡徐坤 / 蔡旭坤 / …），长句建议直接连写，超过阈值会自动回退单条。
- **码表**：`dicts/pinyin_reverse.dict.yaml`（13.4 万词条的第三方拼音词库）导出，不含辅助码；
  预编译为 `models/pinyin.codes.*` 分页索引，反查每键约 10ms，首次使用没有建库停顿。
- **按键纠错**：纠错开关（✨ 注释）对拼音反查同样生效。
- **虎码 + 拼音混输（v0.3.8）**：同一句里可以写虎码，再插入 `` `jiyu `` 这样的拼音块；
  拼音块在词库里命中词条（觊觎）后作为整体参与组句，其余字母自动按虎码解析。
  例：`je`jiyubeuegmmup` → 他觊觎她的美貌。
  虎码部分可以用 `;` / `'` 选重后再接拼音块（如 `j;`iimwwhll` → 什么魑魅魍魉），
  句首的单字母简码（我 `t`、的 `u` …）也可以直接接拼音块（`t`iimwwhll` → 我魑魅魍魉）。
- **三种方案共用同一套反查（v0.3.10）**：虎单、虎词、虎整句的 `` ` `` 前缀反查都由五阶模型 + `pinyin.qp.codes.txt` 生成；
  原万象词库已不再随包发布（仓库内保留以便回滚）。虎单/虎词首次使用反查首键约 20–30ms（换入模型页），之后每键约 3–15ms，常驻约 +20MB。
- 反查候选不再写 zc 用户词典（排序由模型决定）。
- **短输入反查调频（v0.3.12）**：≤8 字母的反查会记录选择次数（`reverse_freq.txt`），
  主动选过一次非首选词后，下次它直接排第一；直接空格选首选不记录。长句不参与。
  `tiger_sentence/reverse_frequency: false` 可关闭，删掉 `reverse_freq.txt` 即清空。

## 简体与繁体

简繁转换有四档：

| 档位 | 选项 | 含义 |
|---|---|---|
| 简体 | `s2s` | 不转换 |
| 通繁 | `s2t` | 简体到通用繁体 |
| 港繁 | `s2hk` | 简体到香港繁体 |
| 臺繁 | `s2tw` | 简体到台湾正体 |

转换链路为：

1. 简体先经过 `STCharacters.txt`、`STPhrases.txt` 和地区专名预置表转为通繁。
2. 港繁继续经过 `HKVariantsPhrases.txt`、`HKVariants.txt`。
3. 臺繁继续经过 `TWVariantsPhrases.txt`、`TWVariants.txt`。

`Ctrl+O` 和 `Ctrl+Shift+4` 用于在简体与通繁之间切换。港繁和臺繁需要从方案菜单选择。转换缓存位于 `lua/replacer.userdb`，词表变化后会自动重建；如果缓存异常，可以删除该缓存并重新部署。

当前实现不对 CJK 兼容区字形做统一规范化。这是有意保留的行为：兼容区字形在三张虎码码表中可能承担不同候选，强行规范化会减少或合并候选。

| `//07` 或 `/qcjs` | 清除极速数据 |
| `//08` 或 `/qcsz` | 清除生字和生词 |
| `//09` 或 `/qctj` | 清除统计，保留生涯数据 |

## 用户数据与升级

以下文件属于用户数据，不是方案运行文件。升级时应保留，不要用发行包覆盖：

| 路径 | 作用 |
|---|---|
| `custom_phrase.txt` | 自造词 |
| `tiger_sentence.options.yaml` | 虎整句开关和档位 |
| `自学习-tiger_sentence.txt` | 虎整句文本学习记录 |
| `自学习锁-*.userdb` | 学习文件的跨进程锁 |
| `lua/input_stats_*.lua` | 输入统计 |
| `lua/kc_count.txt`、`lua/kc_total.txt`、`lua/kc_last.txt` | 击键计数 |
| `lua/replacer.userdb` | 简繁转换缓存，可以安全删除并重建 |

旧版的 `tiger_sentence_learning_*.userdb` 不再被读取。新版学习记录在 `自学习-tiger_sentence.txt`。丢失学习库不会影响方案启动，但会失去已有的整句学习效果。

### 推荐升级流程

1. 备份用户目录中的个人配置和上表列出的用户数据。
2. 解压新 Release。
3. 替换方案、`lua/`、`models/`、词表和其他运行依赖。
4. 如果之前修改过 `rime.lua` 或 `.custom.yaml`，以新版为基础重新合并自己的改动。
5. 保留 `custom_phrase.txt`、`tiger_sentence.options.yaml`、`自学习-tiger_sentence.txt`、统计文件。
6. 重新部署，并检查日志。

### 回滚

回滚时重新安装上一个 Release，再重新部署。方案文件可以回滚，但学习文本、统计和自造词属于用户数据，不会自动回到旧版本状态。如果需要精确回滚，应连同用户数据一起备份和恢复。

## 手机精简版

Android 前端如果部署时出现：

```text
Error loading prism for dictionary 'wanxiang_pro'
```

说明手机没有足够时间或内存编译完整的 `wanxiang_pro` 拼写索引。桌面端完整词库的编译产物约为 table 96 MB、prism 30.6 MB，手机端可能失败。

手机精简版位于仓库的 `手机精简版/`，不进入 Release 压缩包。安装方法：

1. 用 `手机精简版/wanxiang_pro.dict.yaml` 覆盖用户目录根目录下的同名文件。
2. 把 `手机精简版/dicts/zi.common.dict.yaml` 放进用户目录的 `dicts/`。
3. 删除旧的 `build/wanxiang_pro*.prism.bin`，避免前端复用旧 prism。
4. 重新部署并等待编译完成。

精简版保留常用字反查、多音词组和错音兼容，体积约为 table 380 KB、prism 4.7 MB。失去生僻字反查和来自大词库的词组联想反查。桌面端不读取 `手机精简版/` 子目录，因此不受影响。

如果报错路径中出现两次用户目录，例如：

```text
/sdcard/android/rime//sdcard/android/rime/lua/data/charset.reverse.bin
```

这是旧版 librime 的路径拼接问题，不是词库过大问题。当前版本已经在 `lua/wanxiang/charset_filter.lua` 中使用相对路径修复，Android 反查不会再因为这个路径问题失效。

## 常见问题

### 方案菜单里没有虎整句

检查用户目录根部的 `default.custom.yaml`，确认 `schema_list` 包含：

```yaml
- {schema: tiger_sentence}
```

然后重新部署。

### 虎整句部署时报模型错误

检查 `models/sentence-fivegram-mobile.bin` 是否为完整二进制文件。通过 Git 克隆但没有拉取 LFS 时，文件可能只是文本指针。运行 `git lfs pull`，或者直接使用 Release 压缩包。

### 部署很慢或占用很大

完整万象词库和五阶模型体积较大。桌面端首次部署需要编译词典和 prism；手机端优先使用 `手机精简版/`。不要删除 `models/`，否则虎整句无法正常组句。

### 拼音反查在 Android 上报错

先确认是否出现重复用户目录路径。如果是，使用当前 `lua/wanxiang/charset_filter.lua`。如果错误是 `wanxiang_pro.prism.bin` 无法生成，则使用手机精简词库。

### 自造词不生效

检查用户目录是否存在 `custom_phrase.txt`，文件是否可写，词条是否使用 Tab 分隔。新造词在当前会话应立即生效；手工编辑文件后需要重新部署。

### 简繁转换结果异常

删除 `lua/replacer.userdb` 后重新部署，让缓存按当前词表重建。港繁和臺繁需要从方案菜单选择，不能只靠 `Ctrl+O` 切换。

### 英文段空格或 Tab 行为不符合预期

确认使用的是虎整句方案。英文段内单次空格会进入英文原文，连续两次空格会退出英文段；按过 `Tab` 后输入字母或空格会替换成高亮候选。英文段用 `]` 闭合后，空格才用于上屏候选。
