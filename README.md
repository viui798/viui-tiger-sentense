# 芝士虎整

芝士虎整是基于 Rime 的虎码输入方案包，面向希望用虎码输入单字、词组和连续句子，并在同一套方案中使用造词、拼音反查及常用辅助工具的用户。它把虎单、虎词和虎整句整合在一起；虎整句采用 D89-r3 语言模型进行连续输入和候选排序。

## 主要功能

- **三种虎码方案**：`tiger`（虎单，单字优先）、`tigress`（虎词，词组优先）、`tiger_sentence`（虎整句，连续输入组句）。可从 Rime 方案菜单切换。
- **自造词**：用反引号进入造词模式，选择并上屏后写入 Rime 用户目录的 `custom_phrase.txt`；普通输入时可立即查到。也可将刚上屏的词通过“最近”候选绑定到指定编码。支持为已有自造词编码加 `/` 后选择“删词”候选。
- **拼音反查**：在虎码方案中以单引号开头查拼音，支持小鹤双拼、全拼、自然码、微软双拼和搜狗双拼；可用 `/flypy`、`/pinyin`、`/zrm`、`/mspy`、`/sogou` 切换打法。
- **常用辅助工具**：快符、拆字注释、拼音和 Emoji 候选、Unicode 字符集提示与编码显示、简体/通繁/港繁/臺繁切换、计算器、数字转中文大写、符号菜单、日期时间及输入统计。具体按键和命令见 [`芝士虎整说明.md`](芝士虎整说明.md)。
- **虎整句辅助**：D89-r3 五阶模型组句，提供按键纠错档位、候选遍历和选择学习等功能；也支持用 `[` 和 `]` 包住英文片段，在一段中文输入中插入英文，并在英文段未闭合时提供词典联想。方案选项由 Rime 保存于用户目录。

## 安装

1. 安装并启动 Rime 前端（例如 Windows 小狼毫或 macOS 鼠须管），找到该前端的 **Rime 用户目录**。
2. 将本方案包中的文件和文件夹复制到用户目录，保留原有目录层级。不要只复制 `.schema.yaml`：词典、`lua/`、`opencc/`、`models/`、`dicts/`、`tiger_dicts/` 和 `zuci/` 等依赖也需要一并保留。若系统询问是否合并文件夹，选择合并；对已有个人配置先行备份。
3. 确认 `default.custom.yaml` 中包含需要使用的方案。随包配置默认列出虎单、虎词、虎整句和万象拼音反查方案。
4. 在 Rime 前端执行“重新部署”。部署完成后，从方案菜单选择虎单、虎词或虎整句。

Rime 用户目录随操作系统和前端而异。常见位置是鼠须管的 `~/Library/Rime`，以及小狼毫的 `%APPDATA%\Rime`；请以所用前端设置中显示的用户目录为准。更新方案时保留用户目录里的个人配置、`custom_phrase.txt`、虎整句选项与学习数据。

**手机 / Android 前端**：若部署时因 `wanxiang_pro` 词库过大而失败（弹出 `Error loading prism for dictionary 'wanxiang_pro'`），可用 [`手机精简版/`](手机精简版/安装说明.md) 里的精简词库——把该目录的 `wanxiang_pro.dict.yaml` 覆盖到用户目录根、`dicts/zi.common.dict.yaml` 放进 `dicts/`，编译产物会从 table 96MB + prism 30.6MB 降到约 380KB + 4.7MB。该目录是附加内容，**桌面端不受影响**（Rime 不读取子目录）。

## 使用

### 虎码输入与方案切换

选中虎单、虎词或虎整句方案后，按虎码编码输入；`Space` 上屏首选，候选窗口中的数字或配置的选重键可选择其他候选。用方案菜单或 `Ctrl+grave`（Ctrl 加反引号）切换方案；小狼毫配置还列有 `Ctrl+F8`。虎整句的纠错和提前上屏等选项可通过方案选项调整。

### 自造词

有两种造词方式：

1. **从编码候选造词**：输入反引号 `` ` `` 加虎码编码，选择想加入的词并上屏。
2. **将刚输入的词绑定到编码**：先正常输入并上屏该词，再输入反引号和目标虎码编码，选择标记为 `〔最近〕` 的候选并上屏。

成功造词后，词条会写入用户目录的 `custom_phrase.txt`，无需重新部署即可在当前会话中按编码查找。词库格式为每行 `词<TAB>编码[<TAB>权重]`，字段间必须使用 Tab；以 `#` 开头的行为注释。包内的 `custom_phrase.example.txt` 是手工维护模板，不会自动加载。手动编辑 `custom_phrase.txt` 后需重新部署。

删除时输入该词编码并加 `/`，从出现的自造词候选中选带 `〔删词〕` 标记的项目。只有该编码下存在自造词时，`/` 才作为删词入口。

自造词文件是 Rime 用户数据，不包含在方案包中。若需在多台设备间使用同一词库，请自行将 `custom_phrase.txt` 同步或复制到各设备的 Rime 用户目录。

### 拼音反查和辅助命令

- 拼音反查例：输入 `'nihao`；默认打法为小鹤双拼，也可用 `/pinyin` 切到全拼。
- 快符：输入分号加映射字符，例如 `;a`；完整映射见 `kf.dict.yaml`。
- 计算器：输入 `=1+2`，从候选中选择结果。
- 日期时间：虎整句方案可用 `/date`、`/time`、`/week` 等命令。
- 输入统计：`//1` 查看今日统计，`//2` 本周，`//3` 本月，`//4` 本年，`//5` 生字词，`//6` 或 `/scj` 查看生涯段位；`//11` 等为详细统计，`//60` 查看皮肤统计。
- 方案开关和按键会因方案及前端而异。请参照 [`芝士虎整说明.md`](芝士虎整说明.md) 中的辅助功能速查表。

### 虎整句中英混输

仅在虎整句方案中，空闲时按 `[` 或 `]` 会显示各自四个键帽符号候选（左键 `【`、`{`、`[`、`「`；右键 `】`、`}`、`]`、`」`），可用空格或 Tab 选取；正在输入中文编码时按 `[` 进入英文，再按 `]` 返回虎码整句。空闲时按 `[` 后若直接继续输入字母，也会转入英文模式。英文段未闭合且输入至少两个英文字母时，会根据随包 `dicts/en.dict.yaml` 提供词典联想；原样输入仍保留为候选。示例 `前段虎码[OpenAI]后段虎码` 可在一段组合输入中混合中文和英文；括号只标记英文区间，不会提交前面的中文，按 `[` 后、输入英文第一个字母前显示 `[西文]`，开始输入英文后隐藏；按 `]` 后、开始输入中文前显示 `[中文]`，开始输入中文后隐藏，整段可一起选词上屏。

英文段未闭合时给出的词典联想候选，注释会显示该单词的中文释义（数据来自随包 `lua/data/english_chinese.txt`，取自万象）；词库中没有的词仍显示「英文词典」。

英文段里的空格属于英文原文：按 `[` 进入英文后，空格会把空格加进候选（可以打 `[hello world]`），不会上屏；只有按 `]` 结束英文段之后，空格才上屏候选。

## 输入与输出示例

以下示例说明输入流程；可用候选取决于当前码表、安装的依赖和个人词库。

| 输入 | 操作 | 输出/效果 |
|---|---|---|
| `;a` | 快符候选立即上屏 | 输出该快符在 `kf.dict.yaml` 中对应的符号 |
| `前段虎码[OpenAI]后段虎码`（虎整句） | `[` 开始英文，`]` 结束英文，再选候选 | 中文候选、`OpenAI`、中文候选一起上屏 |
| `=1+2` | 选择计算结果 | `3` |
| `'nihao` | 在默认小鹤反查模式下选择候选 | `你好`（具体拼写也可随 `/pinyin` 等命令切换） |
| 先正常输入并上屏 `新词`，再输入 `` ` `` 加它的虎码编码 | 选择 `新词〔最近〕` 并上屏 | `新词` 被加入自造词库；之后输入该编码可见 `新词〔自造词〕` 候选 |
| 在已有自造词的编码后输入 `/` | 选择 `〔删词〕` 候选 | 该词从 `custom_phrase.txt` 移除 |
